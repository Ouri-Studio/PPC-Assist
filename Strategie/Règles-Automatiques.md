# Règles Automatiques PPC

## Règles d'enchères automatiques
- Augmenter les enchères si ACOS < 15%
- Diminuer les enchères si ACOS > 25%
- Pauser les mots-clés avec 0 conversion sur 7 jours
- Augmenter budget pour produits convertissant

## Règles de gestion des annonces
- Pauser annonces avec CTR < 1% après 100 clics
- Supprimer annonces non approuvées après 48h
- Dupliquer annonces avec CTR > 3%
- Tester variantes tous les 7 jours

## Règles de budget
- Répartition : 50% campagne-1, 50% campagne-2
- Pause automatique si ACOS global > 30%
- Augmentation si ROI > 3x dépenses

## Mots-clés automatiques
- Ajouter mots-clés négatifs tous les 5 jours
- Augmenter bid pour termes convertissant
- Mettre en pause termes non performants

## Monitoring automatique
- Alerte si budget quotidien dépassé
- Alerte si ACOS > seuil défini
- Rapport quotidien des anomalies
