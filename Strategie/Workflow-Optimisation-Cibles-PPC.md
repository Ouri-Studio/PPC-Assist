🎯 Workflow Premium — Optimisation des Cibles & Termes de Recherche
(à placer dans /Strategie/Workflow-Optimisation-Cibles-PPC.md)
---
🟦 1. Introduction
Ce workflow décrit la méthode professionnelle d'optimisation des cibles et des termes de recherche dans Amazon Ads.
Il sert de référence stratégique pour :
• réduire les dépenses inutiles,
• améliorer la rentabilité,
• renforcer la pertinence des campagnes,
• et structurer un système PPC propre, stable et scalable.
Ce document est conçu pour être utilisé quotidiennement, hebdomadairement et mensuellement.
---
🟦 2. Objectifs du workflow
• Identifier les cibles non rentables.
• Optimiser les enchères au niveau le plus précis.
• Détecter les termes de recherche performants et les promouvoir.
• Exclure les termes non pertinents ou trop coûteux.
• Maintenir une structure PPC propre et cohérente.
• Documenter les décisions dans le Journal PPC.
---
🟦 3. Préparation (1 minute)
Avant de commencer :
1. Ouvrir l'onglet Cibles dans Amazon Ads.
2. Choisir la période d'analyse :
	◦ 7 jours → micro-ajustements
	◦ 14 jours → décisions intermédiaires
	◦ 30 jours → décisions importantes
	◦ 90 jours → tendances longues
3. Vérifier que les colonnes suivantes sont visibles :
	◦ Impressions
	◦ CTR
	◦ Clics
	◦ Conversion
	◦ Commandes
	◦ Coût
	◦ CA
	◦ ACOS
---
🟦 4. Filtrage intelligent (3 minutes)
🎯 Objectif : isoler les cibles qui dépensent sans vendre.
Appliquer les filtres suivants :
🔍 Filtre 1 : Coût ≥ 3 $
Élimine les petites dépenses sans impact.
🔍 Filtre 2 : CA ≤ 0
Garde uniquement les cibles qui n'ont généré aucune vente.
🔍 Tri : Coût décroissant
Permet d'identifier immédiatement les plus grosses fuites de budget.
---
🟦 5. Analyse des cibles (5 minutes)
Pour chaque cible filtrée, analyser les métriques suivantes :
📌 CTR (Taux de clics)
• < 0.3 % → mauvaise pertinence → désactiver
• 0.3–0.7 % → moyen → baisser l'enchère
• 0.7 % → bon → vérifier conversion
📌 Clics
• < 10 clics → pas assez de données
• 10–20 clics → début de tendance
• 20 clics sans vente → désactiver
📌 Conversion
• < 5 % → mauvais → couper ou baisser
• 5–15 % → moyen → ajuster
• 15 % → bon → augmenter si rentable
📌 ACOS
• 100 % → désactiver
• 50–100 % → baisser
• 20–50 % → optimiser
• < 20 % → augmenter l'enchère
---
🟦 6. Actions recommandées (5 minutes)
🔻 BAISSER l'enchère si :
• CPC trop élevé
• CTR bon mais conversion faible
• ACOS trop haut
• 10–20 clics sans vente
🔺 AUGMENTER l'enchère si :
• CTR bon
• conversion bonne
• ACOS rentable
• faible impression share
❌ DÉSACTIVER si :
• 20 clics sans vente
• CTR < 0.3 %
• ACOS catastrophique
• coût > 3 × CPC moyen
🚫 NÉGATIVER si :
• terme non pertinent
• terme trop large
• terme qui attire un mauvais trafic
• terme qui dépense régulièrement sans vendre
---
🟦 7. Analyse des Termes de Recherche (5 minutes)
Aller dans l'onglet Termes de recherche.
🎯 Identifier :
• Performants → ajouter en EXACT
• Moyens → surveiller
• Mauvais → négativer
• Hors sujet → négativer immédiatement
🔁 Cycle d'optimisation :
1. Terme performant → ajouter en EXACT
2. Terme moyen → surveiller
3. Terme mauvais → négativer
4. Terme hors sujet → négativer immédiatement
---
🟦 8. Mini‑checklist quotidienne
• Filtrer Coût ≥ 3 $
• Filtrer CA = 0
• Trier par coût
• Désactiver les pires cibles
• Baisser les enchères trop élevées
• Vérifier les termes de recherche
• Ajouter les bons termes en EXACT
• Négativer les termes hors sujet
• Noter les actions dans le Journal PPC
---
🟦 9. Mini‑checklist hebdomadaire
