# Structure des Campagnes

## Hiérarchie des campagnes
```
PPC-Assist
├── Campagne-1 (Produit A)
│   ├── Groupe 1 - Keywords génériques
│   ├── Groupe 2 - Keywords marque
│   └── Groupe 3 - Keywords long-tail
├── Campagne-2 (Produit B)
│   ├── Groupe 1 - Keywords génériques
│   ├── Groupe 2 - Keywords marque
│   └── Groupe 3 - Keywords long-tail
└── Campagne-3 (Remarketing)
    └── Groupe 1 - Public audiences
```

## Conventions de nommage
- Campagnes : `[Produit]-[Type]` (ex: Produit-A-Search)
- Groupes : `[Zone]-[Type]` (ex: Paris-Brand)
- Annonces : `[Variante]-[CTA]` (ex: V1-BuynNow)
- Mots-clés : Basés sur l'intention utilisateur
