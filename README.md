# PPC-Assist

Outil d'assistance pour la gestion des campagnes PPC (Pay-Per-Click).

## Structure du projet

- **Analyse** : Modèles et outils d'analyse des campagnes PPC
- **Checklists** : Listes de vérification quotidiennes, hebdomadaires et mensuelles
- **Strategie** : Documentation stratégique et optimisations
- **Journal** : Journaux de suivi et de tests
- **Donnees** : Données historiques et notes importantes
